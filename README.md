

## Exploratory Data Analysis
- `stats.py`: basic statistics of tags, tags co-occurrence, text/code lengths, missing values, and dates.
- `label_noise.py`: inconsistencies between tags ("trees" without "graphs", math-related tags missing "math").
- `signals.py`: how well each keyword pattern finds each tag (precision and recall)
- `plots.py`: the functions that draw the figures
- `report.py`: assembles everything into reports/eda/eda_report.md
